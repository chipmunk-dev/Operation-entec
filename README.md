# Operation CNS Elect

LG CNS 전자팀의 운영 업무에서 반복되는 데이터 정리와 전달 문구 작성을 빠르게
처리하기 위한 **브라우저 기반 업무 보조 도구**입니다.

탭으로 구분된 데이터를 붙여넣으면 해외 메일, 지속 이벤트 재전달 문구,
G-EMS 메시지, 백업 오류 목록, 지속 메시지 엑셀 보고서 등 필요한 형식으로
변환할 수 있습니다.

각 메뉴 상단의 작업 순서 안내를 따라 입력부터 결과 복사·파일 추출까지 진행할 수
있으며, 해외메일 작성은 입력과 결과를 위아래로 배치해 마우스 이동을 줄였습니다.
모든 메뉴의 `사용방법` 버튼은 호버·키보드 포커스·모바일 터치로 열리며,
아이콘 애니메이션과 짧은 단계별 설명으로 해당 기능의 작업 흐름을 안내합니다.
새 버전이 배포되면 열려 있는 화면 상단에 새로고침 안내가 표시됩니다.

> 모든 데이터 가공은 브라우저에서 처리됩니다. 자동 백업 에러 보고의 임시
> 데이터는 현재 브라우저에 최대 7일 동안 저장되며, 다른 PC와 공유할 때는
> 사용자가 직접 JSON 파일로 내보내고 불러옵니다.

## 주요 기능

### 해외메일 작성

- Host, Message, Date, IP가 포함된 데이터를 영문 장애 알림 메일로 변환
- 입력 데이터의 열 순서 변경 지원
- Message와 확인내역 내부의 탭·줄바꿈 자동 복구
- 각 이벤트의 앞·뒤와 이벤트 사이를 하이픈 구분선으로 나눈 메일 본문 생성
- 완성된 메일 내용을 클립보드로 복사

### 담당자 제거·메신저 최적화

- 한 줄의 `호스트 + 탭 + 메시지` 데이터를 한 건 또는 여러 건으로 입력
- 메시지 내부의 추가 탭을 공백으로 정리하고 날짜형 확인 내역 제거
- `확인 내역만 제거`와 이름·직급이 포함된 `메신저 보고 양식 자동완성` 제공
- 항상 표시되는 간략 설정에서 출력 방식을 선택하고 완성된 메시지를 클립보드로 복사
- 입력한 보고자 이름을 현재 브라우저에 12시간 동안 임시 저장

### 자동 백업 에러 필터

- `P-EUBKMST`, `NBUMASTER`, `EXTMASTER` 백업 존별 데이터 처리
- Status 코드가 `0` 또는 `1`이 아닌 백업 작업만 추출
- 정책 이름, 백업 시작 시간, 에러 코드를 구분하여 표시 및 복사
- 한국어와 영어 형식의 백업 시작 시간 지원
- 백업존 원본 입력과 열 설정을 공유 JSON 파일로 내보내기 및 불러오기

### 지속 이벤트 재전달

- 이벤트 원문과 처리 기록을 분리하여 표시
- 독립된 `s/S` 시작 또는 `skip/스킵` 포함 확인내용을 별도 검토하고 `skip/스킵 + x/X`는 제외
- 전달 대기 및 확인 완료 상태 관리
- 국내·해외 메신저와 공통 구분선·아웃룩 정렬용 공백이 적용된 Resend 해외메일 문구 생성
- 괄호가 포함된 처리 내용의 원본/괄호 제외 문구 제공

### 아이체크 보고

- 아이체크 엑셀의 16열 데이터를 복사해 붙여넣는 방식으로 입력
- 확인일·고객사·호스트명·장비 위치·제조사·유형·모델·이상 상태 등 열 판독
- 엑셀의 따옴표 포함 여러 줄 내역 복구 및 완전히 동일한 행 중복 제거
- 장비 위치·호스트명·이상 상태를 서버 담당자별로 자동 그룹화
- 보고자 이름·직급이 포함된 담당자별 메신저 보고 문구 생성 및 개별 복사
- 보고자 이름을 G-EMS 메신저 도구와 공유해 브라우저에 12시간 임시 저장

### 점등 내역 편집

- 기존 점등 내역에 아이체크에서 확인한 점등·소등을 한 번에 반영
- `A-15(3)`처럼 괄호로 적은 자리별 개수 인식 및 증감 반영
- 콤마 뒤의 맨숫자는 앞에 나온 구역 글자를 이어받아 판독
- 없던 구역은 새로 만들고 소등으로 0 이하가 된 자리는 목록에서 제거
- 구역별로 펼쳐 추가·변경·삭제된 자리를 색으로 구분해 확인
- 머리말의 개수 표기를 총 점등 수로 갱신하고 원문 줄 구조는 그대로 유지
- 인식하지 못한 조각과 기존 내역에 없는 소등 자리를 별도로 안내

### 지속 메시지 엑셀 추출

- 입력 데이터의 발생일시를 계산이나 변환 없이 그대로 사용
- 확인내역에서 `성명 + 직급` 형식의 담당자 자동 추출
- 복수 담당자 선택 및 미검출 담당자 직접 입력 지원
- 직접 입력한 담당자는 Enter 또는 확정 버튼을 눌렀을 때만 반영
- 특이사항별 엑셀 제외 및 특이사항 전체 일괄 제외 지원
- 담당자를 복수 선택하면 담당자별로 각각 별도 행 생성
- 담당자 필터, 헤더 고정, 열 너비와 줄바꿈이 적용된 `.xlsx` 파일 생성
- 모든 파싱과 파일 생성은 브라우저에서 처리

## 시작하기

### 새 배포 알림

프로덕션 빌드마다 `version.json`에 고유한 빌드 버전을 생성합니다. 열려 있는 앱은
15분마다 최신 버전을 확인하며, 브라우저 탭으로 돌아오거나 네트워크가 다시
연결됐을 때도 즉시 확인합니다.

새 배포가 확인되면 화면 상단에 안내 배너와 `새로고침` 버튼이 나타납니다.
작성 중인 입력이 사라지는 것을 막기 위해 자동으로 새로고침하지는 않습니다.
특히 지속 이벤트 재전달 작업 중에는 작업을 마친 뒤 새로고침하도록 배너에
주의 문구를 함께 표시합니다.
`version.json`과 `index.html`은 Netlify의 `public/_headers` 설정을 통해 이전
배포가 캐시되지 않도록 구성했습니다.

## 입력 데이터 형식

대부분의 기능은 엑셀이나 운영 도구에서 복사한 **탭 구분 데이터**를
입력으로 사용합니다. 한 줄은 하나의 작업 또는 이벤트를 나타냅니다.

### 해외메일 및 지속 이벤트

기본 열 순서는 다음과 같습니다.

```text
Host    Message/Event    Date    IP
```

화면의 입력 순서 설정에서 각 열의 의미를 변경할 수 있습니다.

### 자동 백업 에러 필터

최소 9개의 열이 필요하며 다음 위치의 값을 사용합니다.

| 위치 | 필드 | 용도 |
| ---: | --- | --- |
| 1번째 열 | Status | 오류 여부 판단 |
| 6번째 열 | Job Policy | 정책 이름 표시 |
| 7번째 열 | Start Time | 백업 시작 시간 표시 |

권장 열 순서:

```text
Status    State    Operation    State Details    Job Schedule
Job Policy    Start Time
```

화면의 열 순서 설정에서 각 필드의 위치를 입력 데이터에 맞게 변경할 수 있습니다.

### 아이체크 보고

아이체크 엑셀에서 다음 16개 열을 순서대로 복사해 붙여넣습니다.

```text
확인일    고객사    호스트명(서버명)    장비 위치    제조사    유형
장비 모델명    기타값    이상 상태    확인 근무자 조    확인 근무자 이름
서버 담당자(어드민)    미처리    유지중    소등    내역
```

보고 문구에는 장비 위치, 호스트명, 이상 상태를 사용하며 12번째 열의 서버
담당자를 기준으로 여러 장비를 한 메시지에 묶습니다. 헤더와 빈 줄은 제외하고,
16개 열이 완전히 같은 중복 행은 한 건만 유지합니다. 내역 셀 안의 줄바꿈은
엑셀의 따옴표 범위를 판독해 같은 행으로 복구합니다.

### 점등 내역 편집

기존 내역은 엑셀의 점등내역 셀을 그대로 붙여넣습니다. 구역은 `/`로, 자리는
쉼표로 구분하며 여러 줄로 나뉘어 있어도 원문 줄 구조를 유지합니다.

```text
점등(95ea) : A-15(3),21/B-01-3,15,18
```

점등·소등 입력은 쉼표나 줄바꿈으로 구분하고 구역 글자를 붙여 적습니다. 같은
자리가 여러 개면 `D-24(2)`처럼 개수를 함께 적으며, 구역 글자가 없는 조각은
반영하지 않고 화면에 그대로 안내합니다.

머리말의 `(95ea)`처럼 괄호로 적은 개수 표기는 반영한 뒤의 총 점등 수로
갱신하고, 개수 표기를 찾지 못하면 개수만 세고 원문을 그대로 둡니다.

### 지속 메시지 엑셀

기본 열 순서는 다음과 같습니다.

```text
지속시간    그룹명    호스트    내용    발생일시    IP
```

화면에서 여섯 필드의 순서를 입력 데이터에 맞게 서로 교환할 수 있습니다.
기본값은 발생일시를 5번째 열, IP를 6번째 열로 읽습니다. 입력한
발생일시는 별도 계산이나 변환 없이 출력 파일에 그대로 사용합니다.

내용 필드 내부에 탭이나 줄바꿈이 섞인 경우에는 현재 열 순서에서 `내용` 앞의
필드를 왼쪽부터, 뒤의 필드를 오른쪽부터 먼저 복원합니다. 그 사이에 남은
조각은 모두 하나의 내용으로 합치며, 자동 복구된 행은 특이사항에 표시됩니다.
내용 외 필드가 부족하거나 안정적으로 확인되지 않는 행은 추출 전에 확인이
필요한 데이터로 분류합니다.

내용 끝의 날짜형 처리 기록 또는 `확인내역:` 이후 내용을 분리하고, 그 안에서
`정민규 책임`, `정민규책임`처럼 입력된 담당자를 찾습니다. 출력 파일은 다음
열로 구성됩니다.

확인내역의 `->`, `→`, `>` 뒤에서 다음 화살표가 나오기 전에 `재전달`
키워드가 발견되면 해당 화살표부터 뒤쪽은 담당자 판독에서 제외합니다. 화살표
뒤에 `재전달`이 없거나, `재전달`보다 다음 화살표가 먼저 나오면 그 구간은
담당자 판독 범위에 유지됩니다.

담당자 판독 범위에 `LGEVH 메일`, `LGEEG 메일`, `LGERA 메일`처럼
`영문 코드 + 메일` 형식이 있으면 국내 근무자 이름보다 우선하여 영문 코드
자체를 담당자로 사용합니다. 코드가 여러 개면 복수 담당자와 동일하게 선택할
수 있습니다.

`cicop`과 `infra`는 담당자 판독 범위에 단독으로 있어도 해당 키워드를
담당자로 사용합니다. `해외클라우드 메신저`와 `해외클라우드운영 메신저`는
모두 `해외클라우드운영` 담당자로 묶습니다. 영문 코드 뒤의 `메일` 담당자와
해외클라우드 담당자가 동시에 발견되면 메일 담당자를 우선하고
`해외클라우드운영`은 제외합니다. 재전달 제외 범위 안에만 있는 키워드는
담당자로 인식하지 않습니다.

`TRAN VAN SON, Peter 메신저`, `TRAN VAN SON 메신저`,
`NGUYEN DUC ANH 메신저`는 모두 동일한 해외 담당자로 보고 엑셀 담당자 값을
`TRAN VAN SON, Peter`로 통일합니다. 같은 확인내역에 표현이 중복되어도 한
명의 담당자로만 생성합니다.

`infra`가 있는 담당자 판독 범위에 `(dba 김철수 선임)`처럼 `dba`로 시작하는
괄호가 있으면 `infra` 대신 괄호 안의 `성명 + 직급`을 담당자로 사용합니다.
`dba`는 대소문자를 구분하지 않으며, 괄호 안에서 여러 명이 확인되면 복수
담당자로 처리합니다.

```text
No.    발생일시    지속시간    어드민    호스트명    내용    IP    그룹명
```

## 데이터 처리 및 보안

- 모든 메시지 파싱과 결과 생성은 브라우저에서 수행합니다.
- 입력 데이터는 외부 API나 데이터베이스로 전송되지 않습니다.
- 자동 백업 에러 보고의 원본과 열 설정은 현재 브라우저에 최대 7일 동안
  임시 저장되며, 나머지 화면 상태는 새로고침하면 사라집니다.
- 자동 백업 화면에서 JSON 파일을 내보내면 세 백업존의 원본 입력, 열 설정,
  선택된 백업존이 파일에 포함됩니다.
- 전달받은 JSON을 불러오면 파일 형식, 버전, 용량, 데이터 구조를 검증한 후
  현재 화면의 백업 입력과 열 설정을 교체합니다.
- 결과 복사 기능을 사용할 때만 브라우저 Clipboard API에 접근합니다.

공유 JSON 파일에는 원본 운영 데이터가 포함되므로 사내에서 허용된 메신저나
공유 폴더를 통해서만 전달하고, 사용이 끝난 파일은 조직의 보안 정책에 따라
관리해 주세요. JSON 공유 과정에도 별도의 서버는 사용하지 않습니다.
